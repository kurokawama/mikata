# MIKATA（ミカタ）— Design Brief

## ブランドアイデンティティ

### サービス名
- **MIKATA** — ローマ字ロゴ
- タグライン: 「世界のミカタ」
- 意味: 見方（perspective）＋ 味方（ally）

### worldview（世界観キーワード）
- 知的好奇心 × グローバル × 朝の爽やかさ
- 多角的視点 × 信頼性 × 発見の興奮
- プリズムのように一つの事実が多色に分かれる
- 地球儀を手に取るような身近なグローバル感

### perplexity_url
- https://www.perplexity.ai/search/news-aggregation-multi-perspective-design-trends-2026

### 感情的北極星
「毎朝、世界の視点で目が覚める」
— 日本メディアだけでは見えなかった世界が、MIKATAを開くと見える。知的好奇心と軽い優越感。

### ブランドパーソナリティ
- **知的だけど親しみやすい**（高圧的でない。友達が教えてくれる感覚）
- **信頼できる**（ソース全件明示。AIの限界も正直に開示）
- **グローバルだけど日本語ネイティブ**（海外メディアの知見を、自然な日本語で）
- **速さより深さ**（速報ではなく翌日の多視点深掘り）

### ブランドカラー（提案）
```
Primary:     #1A1A2E  (Deep Navy — 信頼・知性)
Accent:      #E94560  (Coral Red — 視点の衝突・発見の興奮)
Secondary:   #16213E  (Dark Blue — 補助的な深み)
Background:  #F8F9FA  (Light Gray — 読みやすさ)
White:       #FFFFFF  (カード・本文背景)
Success:     #22C55E  (Green — 肯定的論調)
Danger:      #EF4444  (Red — 批判的論調)
Neutral:     #9CA3AF  (Gray — 中立論調)
```

### タイポグラフィ
- ロゴ: Montserrat Bold（MIKATAのローマ字）
- 見出し: Noto Sans JP Bold (700)
- 本文: Noto Sans JP Regular (400), 16px, line-height 1.75
- 英語混在: Inter

### 空間設計
- セクション: 24px (mobile), 32px (desktop)
- カード: 16px padding, 12px radius, subtle shadow
- 要素間: 8px / 12px / 16px / 24px

## 画面設計（主要5画面）

### 1. トップページ (/)
```
[ヘッダー: MIKATA ロゴ + 検索 + ログイン]
[ヒーロー記事カード（全幅）— 今日の最重要多視点ニュース]
  - 国旗アイコン3-5個 + 「5カ国が報道」バッジ
  - 論調サマリー: 🟢3 肯定 / 🔴1 批判 / ⚪1 中立
[ジャンルタブ: スポーツ | 経済 | ゲーム]
[記事カードリスト（2列PC / 1列モバイル）]
  - サムネイル（16:9） + タイトル + 論調ミニバー + 国旗群
  - カード4枚ごとにネイティブ広告（PR表記）
[ボトムナビ（モバイル）: ホーム | 検索 | 通知 | マイページ]
```

### 2. 記事詳細ページ (/sports/soccer/[slug])
```
[パンくず: ホーム > スポーツ > サッカー]
[記事タイトル（h1）]
[メタ情報: 公開日 | 更新日 | 参照メディア数 | AI分析]
[論調サマリーバー: 🟢3 / 🔴2 / ⚪1 — ワンラインで全体感]

[独自分析本文（800-1200字）]
  - 16px, line-height 1.75
  - 見出し（h2/h3）で構造化
  - 「このニュースのポイント」ボックス（冒頭3行要約）

[--- 広告1枚（PR表記）---]

[各国視点セクション — 背景色 #F5F5F5 で分離]
  [🇬🇧 BBC Sport]
    左端カラーライン: 🟢緑（肯定的）+ ↑アイコン
    一行要約（80字以内）
    [原文を読む →] ボタン
  [🇪🇸 Marca]
    左端カラーライン: 🔴赤（批判的）+ ↓アイコン
    一行要約（80字以内）
    [原文を読む →] ボタン
  [🇯🇵 スポーツ報知]
    左端カラーライン: ⚪灰（中立）+ →アイコン
    一行要約（80字以内）
    [原文を読む →] ボタン

[AI生成表記: 「この記事はAIが分析・生成しました」]
[シェアボタン: X / LINE / コピー]
[関連記事カード 3枚]
```

### 3. 課金ページ (/subscribe)
```
[見出し: 「世界のミカタを、もっと深く」]
[使用実績: 「あなたは先月28記事を無料で読みました」]

[プラン選択（2択のみ）]
  [月額プラン: 980円/月]
  [年額プラン: 9,800円/年（817円/月相当）★おすすめ]
    — 「2ヶ月分おトク」バッジ

[特典リスト]
  ✓ 全記事読み放題
  ✓ 広告非表示
  ✓ 先行配信（朝7時）
  ✓ 週次ハイライトメール

[「いつでも即解約可能」— 大きく表示]
[Stripe Checkout ボタン]
[特商法表記リンク]
```

### 4. 国別視点ページ (/perspectives/spain/)
```
[見出し: 🇪🇸 スペインメディアの視点]
[メディア一覧: Marca / AS / Sport / Mundo Deportivo]
[各メディアの説明（1段落）+ 信頼度ランク]
[このメディアが引用された最新記事リスト]
```

### 5. 管理画面 (/admin)
```
[ダッシュボード]
  - 今日の記事キュー（承認待ち）
  - 広告申込（承認待ち）
  - 本日のPV / 課金者数 / MRR
[記事管理: 一覧 → 承認/却下/編集]
[広告管理: 申込一覧 → 審査結果 → 承認/却下]
[ソース管理: メディアソースDB → RSS巡回状況]
```
