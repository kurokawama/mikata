# MIKATA リバイバルプラン仕様書

**作成日**: 2026-04-12
**案件タイプ**: design（UIリバイバル — L2 UX改善）
**根拠**: CEO指摘「ファーストビューがニュースサイトに見えない」+ 4名討論全員一致(confidence 0.87)

---

## 1. 問題の本質

MIKATAはSaaSランディングページに見える。ニュースサイトに見えない。

**原因**: ファーストビューに「ニュース」がなく「サービス説明」がある。ユーザーはニュースを読みに来たのに、サービスの特徴カードとCTAに迎えられる。UIが「何屋か」を伝えていない。

---

## 2. ゴール（0.5秒ルール）

サイトを開いた瞬間に「各国メディアの視点を比較できるニュースサイトだ」と伝わること。文章で説明しなくても、レイアウトと情報の並べ方だけで伝わる状態。

## 4. 記事カード設計

### ニュースカード必須要素
1. **ジャンルカラー帯**（左4px: スポーツ=緑, 経済=青, ゲーム=紫）
2. **見出し**（Newsreader serif, 2行以内, 太字）
3. **国旗チップ**（🇺🇸🇯🇵🇬🇧 — 最大4カ国、Amber背景）→ 「多視点」が0.5秒で伝わる
4. **論調ミニバー**（4px, green/red/gray比率）
5. **時間**（相対表示「2時間前」）
6. **ソース**（「NHK · スポーツ」）

### 画像問題の解決
AI生成画像は使わない（コスト・著作権リスク）。代わりに:
- **ジャンル別グラデーションプレースホルダー** + **国旗アイコン**
- ヒーロー記事のみ: 背景にDeep Navyグラデーション + 論調カラーアクセント
- 国旗チップが画像の代替として「視覚的な多様性」を提供

### マガジンレイアウト
- ヒーロー記事: **フル幅大カード**（見出し+要約+論調バー+国旗）
- サブ記事: **2列 or 3列の小カード**（見出し+国旗+時間のみ）
- 均一グリッド禁止 → 大+小の混合で視覚的階層を作る

## 5. 各国視点の視覚表現（MIKATA独自の差別化UI）

### 記事カード上
```
[ジャンル色帯] FIFA規制強化、欧州と日本で割れる評価
              🇺🇸🇯🇵🇪🇺🇨🇳  🟢🟢🔴⬜  |  経済  |  3時間前
```
国旗チップ + 論調ミニバーの組み合わせ。カードを見ただけで「このニュースを4カ国で比較できる」が伝わる。

### 記事詳細ページ
```
[MIKATA独自分析 800-1200字]

━━━ 各国メディアの論調 ━━━

🇺🇸 ポジティブ(+0.6)  "市場の自由化を歓迎"   → [AP通信]
🇯🇵 ニュートラル(+0.1) "慎重な評価が目立つ"   → [日経]
🇬🇧 ネガティブ(-0.3)   "規制の抜け穴を指摘"   → [Guardian]
🇫🇷 ネガティブ(-0.5)   "欧州独自路線を主張"   → [Le Monde]

[全体論調サマリーバー: 🟢25% ⬜25% 🔴50%]
```
- タブ切り替えではなく**縦スタック**（スクロールで全国比較）
- 国旗 + 論調色 + スコア + 要約80字 + ソースリンク
- 「え、こんなに違うのか」という驚きを生む視覚配置

## 6. フリーミアムの導線設計

### 感情フロー（理想）
```
開く → 「ニュースがある」（期待）
  ↓
記事を読む → 「日本とアメリカで見方が違う」（発見）
  ↓
3本目の記事 → 「もっと読みたい」（習慣化の芽）
  ↓
壁に当たる → 「あと2つの国の見方が待っています」（自然な動機）
  ↓
登録 → 「毎朝チェックしよう」（習慣化）
```

### 壁の設計
- 記事本文70%でブラー（既存設計通り）
- CTA文言: 「無料で全視点を読む」（「登録してください」ではない）
- 壁の直前に**一番意外な国の論調**を配置（転換率最大化）
- 未登録でも「各国メディアの視点」セクションの**最初の2カ国は見える**。3カ国目以降が壁。

### ヘッダーの認証状態
- 未ログイン: 「ログイン」ボタンのみ（「無料で始める」はファーストビューから削除）
- ログイン済み: ユーザーアイコン + ドロップダウン（設定/ログアウト/管理画面）

## 7. 実装計画

### リバイバルレベル: L2（UX改善）
全面再設計ではない。既存コード・既存ルーティング・既存DBスキーマは維持。変更するのは:
- トップページのコンポーネント構成
- 記事カードコンポーネント
- ヘッダーナビゲーション
- 記事詳細の各国視点セクション

### デザインパイプライン範囲
| 対象 | パイプライン | 理由 |
|------|------------|------|
| トップページ | **Stitch → v0 → Cursor/Codex** | レイアウトが根本的に変わる |
| 記事カード | **Stitch → v0 → Cursor/Codex** | 新しいUI要素（国旗チップ等） |
| 記事詳細（各国視点） | **v0 → Cursor/Codex** | 既存ベース+セクション追加 |
| ヘッダー | **Cursor/Codexのみ** | タブ追加だけ |
| 課金/設定/admin | **変更なし** | リバイバル対象外 |

### 実装順序
1. **ヘッダーにカテゴリタブ追加**（1時間）— 最も低リスクで効果が見える
2. **トップページ: ヒーロー→トップ記事化**（3時間）— CEOの指摘の核心
3. **記事カード: 国旗チップ+論調バー+マガジンレイアウト**（3時間）
4. **記事詳細: 各国視点カード型分離**（2時間）
5. **フリーミアム壁の実装**（2時間）

### ブランドトークン（変更なし）
- Primary: #1A1A2E (Deep Navy)
- Accent: #F59E0B (Amber)
- Headline: Newsreader serif
- Body: Work Sans
- 論調色: positive=#22C55E / negative=#EF4444 / neutral=#9CA3AF

---

## 8. 変えないもの

- DB スキーマ（articles / media_sources / profiles）
- 認証フロー（Supabase Auth + Email/Password）
- デプロイ先（Vercel）
- 技術スタック（Next.js 15 + shadcn/ui + Tailwind）
- ブランドカラー・フォント
- /admin、/settings、/legal 系ページ
